# Student Performance Analysis 📊

## Overview
This project analyzes student performance data to identify patterns and relationships between academic scores and factors such as gender, parental education, parental marital status, and ethnic group.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data cleaning and preprocessing
- Gender and ethnic group distribution
- Parent education vs. student scores
- Parent marital status vs. student scores
- Distribution of Math, Reading, and Writing scores

## Key Findings
- Parental education shows differences in students' average scores.
- Parent marital status does not show a major impact on student performance.
- Student demographics were explored through various visualizations.

## Files
- `Student_Performance_Analysis.ipynb` — Analysis and visualizations
- `Expanded_data_with_more_features.csv` — Dataset
